# 🐍 Jogo da Cobrinha em Python

Projeto desenvolvido em Python utilizando a biblioteca **Pygame**, recriando o clássico jogo da cobrinha com interface gráfica e sistema de pontuação.

## Funcionalidades

- 🎮 Movimentação da cobrinha com o teclado
- 🍉 Coleta de alimentos para aumentar a pontuação
- 🎨 Seleção da cor da cobrinha
- 🏆 Sistema de pontuação e recorde
- 💥 Detecção de colisão com as bordas e com o próprio corpo
- 🔄 Reinício da partida após o fim do jogo

## Tecnologias

- Python 3
- Pygame

## Como executar

1. Instale a biblioteca Pygame:

```bash
pip install pygame
```

2. Certifique-se de que a imagem `melancia.png` esteja na mesma pasta do projeto.

3. Execute o arquivo principal:

```bash
python main.py
```

## Objetivo

Praticar conceitos de desenvolvimento de jogos utilizando Python, incluindo manipulação de eventos, interface gráfica, lógica de movimentação, colisões e controle de pontuação.
